# Projeto Java — Design Patterns

## Sobre o projeto

Este projeto foi desenvolvido como parte da minha jornada de aprendizado na DIO, com o objetivo de praticar os conceitos de Design Patterns (Padrões de Projeto) utilizando Java puro.

O sistema demonstra diferentes formas de enviar notificações, utilizando padrões que ajudam a organizar o código e facilitar sua manutenção.

## Padrões de Projeto utilizados

### 1. Factory

O padrão Factory centraliza a criação dos objetos de notificação, permitindo escolher entre e-mail e SMS sem precisar criar os objetos diretamente no programa principal.

### 2. Strategy

O padrão Strategy permite alterar a forma de envio da notificação durante a execução, utilizando diferentes estratégias sem modificar a estrutura principal do sistema.

## Tecnologias utilizadas

* Java
* Programação Orientada a Objetos
* Interfaces e polimorfismo
* Design Patterns
* Git e GitHub

## Funcionalidades

* Criar notificações por e-mail.
* Criar notificações por SMS.
* Selecionar diferentes formas de envio.
* Demonstrar a aplicação dos padrões Factory e Strategy.

## Como executar

1. Abra o projeto em uma IDE Java ou compilador Java on-line.
2. Execute a classe `Main`.
3. Observe no console as mensagens de notificação e a troca de estratégias.

## Aprendizados

Com este projeto, pratiquei conceitos importantes de Java, como interfaces, classes, métodos e polimorfismo. Também aprendi como os padrões de projeto podem contribuir para um código mais organizado, flexível e fácil de manter.
